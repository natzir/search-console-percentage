Search Console Percentage Calculator by Natzir · Privacy policy

Last updated: 9 October 2026

Search Console Percentage Calculator is a Chrome extension by natzir.com that shows how much each number changed when you compare two periods in Search Console's Performance reports. It has no accounts, no analytics, no ads and no server of its own.

What it reads

Only on Search Console (search.google.com), and only what the Performance report already shows you: the totals cards, the table and the chart, including the values Google's chart shows when the pointer moves over it. All of it is read and processed inside the Search Console page in your browser.

What it keeps

The metric you last chose for the change strip, in chrome.storage.local, in this browser only. A CSV of the table is saved to your computer only when you click Export with %.

What it sends

Nothing. The extension makes no network requests.

Permissions

  • Access to search.google.com: to read the Performance report and add the changes to it.
  • storage: to remember the metric chosen for the change strip.

Contact

Questions and reports: github.com/natzir/search-console-percentage/issues.
